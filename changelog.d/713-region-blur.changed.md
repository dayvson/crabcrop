`blur_region` scales with the region at every size (issue #713). Its sigma is an eighth of the region's shorter side, as docs/filters.md always said, but it stopped at 30, so a region 240 px or more on its shorter side got no more blur than that: large type in a big region could stay legible. `blurfaces` scales with each face and has no such ceiling. The region blur, and the class blurs that use it (`blurclass`), now have none either: a 400 px box blurs at sigma 50. The cost grows with the sigma, so like every blur it checks the processing limit before each row (issue #614) and a region too large to blur in time answers `504`. Regions under 240 px on their shorter side blur as before.
