Every artifact now carries `THIRD-PARTY-NOTICES.md`, the license notices of the third-party code in the `crabcrop` binary (issue #682). It lists the 494 crates the release build compiles for its four targets with `avif-decode`, each with its license and the license texts and NOTICE files it ships, and it reproduces, from their own sources, the licenses of the C and assembly code the binary links: libjpeg-turbo, libwebp, AWS-LC, dav1d and the AV1 assembly in rav1e and av-scenechange, with the Alliance for Open Media Patent License 1.0. It says where the source code of the one crate under a source-availability license, mp4parse (MPL-2.0), is published. The release tarballs carry it beside the binary, the Homebrew formula installs it in its doc directory, and the images install it with `LICENSE` in `/usr/share/doc/crabcrop/`; the AI image adds ONNX Runtime's `LICENSE` and `ThirdPartyNotices.txt` in `/usr/share/doc/crabcrop/onnxruntime/`. `scripts/check_notices.py --write` generates the file with a pinned cargo-about from `Cargo.lock`, `scripts/notices/about.toml` lists the licenses the binary may carry, and CI and the release preflight fail when the file falls behind the crates the release builds or a crate's license is not on that list. Nothing changes for a request.
