`Dockerfile.ai` takes ONNX Runtime 1.31.0 from its NuGet package, `Microsoft.ML.OnnxRuntime` on `api.nuget.org`. It downloaded the release tarballs from GitHub, which have answered `404` since 2026-11-17, so the AI image's build failed (issue #733). The library is the same: the package's `linux-x64` and `linux-arm64` libraries are byte for byte the tarballs', and the build checks them against the same SHA-256 pins, after the package's own. ONNX Runtime's `LICENSE` and `ThirdPartyNotices.txt` come from the package too. A build of `Dockerfile.ai` now reaches `api.nuget.org` for ONNX Runtime where it reached `github.com`; the two models still come from GitHub.
