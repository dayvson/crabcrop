With moderation on CLIP prompts (`CRABCROP_MODERATION_LABELS` without `CRABCROP_MODERATION_MODEL`), boot loads the CLIP models once, for the tag labels and the prompts together, where the prompts loaded them a second time (issue #736). The image model's session is held in memory once instead of twice, and the prompts score over the tags' image model and its memo of the last embedding, so a meta request with `moderation=1` runs the image model once for the tags and the signals, where it ran it twice. The tags, the review signals, their scores and the boot lines are unchanged. The tags and the prompts now share that one session, so a moderation run waits for another request's tagging run on it, as two requests' tagging runs already waited for each other. In the library, `crabcrop::ai::OnnxClipProvider::load_sets` loads the model pair once for several label sets.
