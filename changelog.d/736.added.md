`/metrics` counts the AI model locks taken back after a panic, as the counter `crabcrop_ai_lock_recoveries_total` (issue #736). Since issue #715 a model lock that a request's panic poisoned is taken back by the next request that needs the model, and stderr gets a line for each with the count since boot; the counter is that count, so an alert can watch for a model that keeps panicking on what it is given without reading the logs.
