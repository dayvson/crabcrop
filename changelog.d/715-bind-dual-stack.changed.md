`CRABCROP_BIND=::` now listens on IPv4 too, whatever the host's default (issue #715). The listener took the host's default for `IPV6_V6ONLY`, so a Linux host set to `net.ipv6.bindv6only=1` listened on IPv6 only; it is now bound with the option off, and an IPv4 client shows as an IPv4-mapped address. On a host without IPv6 the boot still stops, now with an error that says to set an IPv4 address such as `0.0.0.0` instead. The default stays `0.0.0.0`, every IPv4 interface. In the library, the new `crabcrop::server::bind_listener` binds the listener this way.
