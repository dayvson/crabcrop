WARNING: no signing secret is configured. The server refuses
to start without CRABCROP_SECRET (16+ bytes). Create one and
point existingSecret at it:

  kubectl create secret generic crabcrop-secret \
    --from-literal=CRABCROP_SECRET="$(openssl rand -hex 32)"
  helm upgrade {{ .Release.Name }} {{ .Chart.Name }} --set existingSecret=crabcrop-secret

Production installs also put a CRABCROP_METRICS_TOKEN key in
the same Secret and set metricsToken.existingSecret to it, so
GET /metrics requires the bearer <redacted>; see
values-production.yaml.
